# pocket-id-mcp

An MCP (Model Context Protocol) server for [Pocket ID](https://pocket-id.org) — a self-hosted, passkey-first OIDC identity provider.

> **Status:** early design phase. Nothing to install yet.

## Goal

Let AI assistants (Claude, etc.) manage a Pocket ID instance through its [REST API](https://pocket-id.org/docs/api): users, groups, OIDC clients, audit logs, and more — with sensible safety tiers around destructive operations.
